# DW장례업무

디더블유 장례의전(DW) 직원이 사용하는 업무 앱입니다. 2026년 10월 23일부터 **관리자 서식 · 장례일정 · DW관리를 「DW장례업무」 하나로 통합**했습니다.

**접속 주소: https://dwfuneral.com/forms/**

직원마다 본인 계정으로 로그인합니다. 기록은 사용하는 기기에 먼저 저장되고, 인터넷이 연결되면 로그인한 계정으로 **Supabase(수파베이스) 서버에도 자동 저장**됩니다.

> **기존 앱을 삭제하거나 재설치하지 마세요.** 앱 삭제나 브라우저 데이터 삭제로 기기에 남은 기록이 함께 사라질 수 있습니다. 통합 앱으로 이동할 때는 **기존 기록 백업 → 본인 계정 로그인 → 기록 확인 → 서버 저장 확인** 순서로 진행하세요. 로그인했다는 것만으로 모든 옛 기록이 옮겨진 것은 아닙니다.

## 1. 접속과 설치

- 안드로이드는 **Chrome**, 아이폰은 **Safari**에서 위 주소를 여세요. 카카오톡 안에서 열었다면 주소를 복사해 해당 브라우저에 붙여 넣으세요.
- 안드로이드: Chrome의 **⋮ → 앱 설치** 또는 **홈 화면에 추가**를 누릅니다. 화면에 「앱 설치」 버튼이 보이면 그 버튼을 써도 됩니다.
- 아이폰: Safari의 **공유 → 홈 화면에 추가 → 추가**를 누릅니다. 설치한 뒤에는 홈 화면의 아이콘으로 여세요. Safari와 홈 화면 앱의 기록 저장 공간은 따로입니다.
- PC: Chrome·Edge에서 접속할 수 있고, 주소창의 설치 아이콘이나 메뉴의 「앱 설치」로 설치할 수 있습니다.
- `https://dwfuneral.com/`으로 접속해도 통합 앱으로 이동합니다. 장례업무와 회사 서류를 각각 새 앱으로 설치할 필요가 없습니다.

**이미 관리자 서식 앱을 쓰고 있다면 그대로 여세요.** 같은 앱이 업데이트되어 DW장례업무로 바뀝니다. 이름이나 화면이 아직 예전 모습이면 인터넷에 연결한 상태에서 앱을 닫았다가 다시 열어 주세요. 업데이트를 위해 삭제할 필요는 없습니다.

## 2. 기존 앱을 지우지 않고 이동하기

1. **기존에 쓰던 휴대폰의 앱 아이콘으로 먼저 엽니다.** 예전 관리자 서식 · 장례일정 · DW관리에 남은 기록을 각각 확인하세요.
2. 장례일정 또는 DW관리에서 「DW장례업무로 합쳐졌어요」가 나오고 **「기록 백업 파일 받기」** 버튼이 보이면 먼저 파일을 받으세요. 아직 예전 업무 화면이 나온다면 아래 백업 표의 설정 메뉴에서 백업합니다. 관리자 서식이 이미 통합 앱의 로그인 화면으로 바뀌었다면 본인 계정으로 로그인한 뒤 「설정 → 데이터」에서 백업하세요.
3. 공유창에서는 **파일에 저장**하거나 본인만 접근할 수 있는 보관 장소를 선택하세요. 공유창을 취소하지 말고, 실제로 `.json` 파일이 저장됐는지 확인하세요.
4. 안내 화면의 **「DW장례업무 열기」**를 누르거나 `https://dwfuneral.com/forms/`을 열어 **본인 계정**으로 로그인합니다. 아이폰에 통합 앱을 새로 설치했다면 설치한 아이콘으로 열고 로그인하세요.
5. 통합 앱에서 기록을 확인합니다. 빠진 기록이 있으면 아래 표에 맞는 **「백업 불러오기」**에서 파일을 선택하세요. 행사·봉투의 해당 월, 주간보고·회의록, 회사 서류 등을 직접 확인합니다.
6. 사용하던 화면을 각각 열어 서버 저장 완료 표시까지 확인합니다. **기존 아이콘은 그대로 두고**, 이후에는 DW장례업무를 사용하세요. 백업 파일도 계속 보관하세요.

예전 주소 `https://dwfuneral.com/jangrye/`와 `https://dwfuneral.com/admin/`를 **브라우저로 열면 통합 앱으로 바로 이동**합니다. 예전 앱 안의 기록을 백업하려면 설치해 두었던 **그 앱 아이콘**으로 여세요. 특히 아이폰은 홈 화면 앱마다 기록이 따로 있을 수 있습니다.

백업 버튼이 보이지 않거나 통합 앱에서 기록이 안 보여도 **기록이 없다고 판단해 앱을 지우지 마세요.** 기존 앱과 기기를 유지한 채 파트장 또는 관리자에게 확인을 요청하세요. 안드로이드에서는 앱들이 같은 사이트의 저장 공간을 사용하므로 예전 앱 하나를 지우는 일이 다른 업무 기록에도 영향을 줄 수 있습니다.

## 3. 회원가입과 로그인

1. 처음 사용하는 직원은 로그인 화면의 **「회원가입」**을 누릅니다.
2. **이메일 · 비밀번호 · 비밀번호 확인 · 이름**을 입력하고 **「가입하기」**를 누릅니다. 비밀번호는 6자 이상이며, 두 비밀번호가 같아야 합니다.
3. 이미 계정이 있으면 **「로그인으로 돌아가기」**에서 가입한 이메일과 비밀번호로 로그인합니다. 기기를 바꿔도 새로 가입하지 않고 **같은 계정**을 사용하세요.

예전 방식으로 받은 아이디가 있다면 이메일 칸에 아이디만 넣어도 됩니다. `@`가 없으면 앱이 `아이디@dwfuneral.com`으로 처리하고, `@`가 있으면 입력한 이메일을 사용합니다.

- 가입만으로 파트장이나 총괄실장 권한이 생기지는 않습니다. 권한이 필요하면 관리자에게 요청하세요.
- 파트 게시판에 소속 파트가 없다고 나오면 **가입한 이메일 또는 아이디를 파트장에게 알려 주세요.** 파트장이 「게시판 → 파트원 관리」에서 추가합니다. 직원 한 명은 한 파트에 소속됩니다.
- 「회원가입 꺼짐」, 「이메일 확인 켜짐」, 「이메일 확인 안 됨」 등이 나오면 표시된 문구를 관리자에게 알려 주세요. 앱 삭제로 해결하는 문제가 아닙니다. 비밀번호는 전달하지 마세요.
- 기존 기록이 남은 기기에서는 그 기록의 주인인 **본인 계정**을 사용하세요. 기기에 남아 있는 기록이 로그인한 계정으로 올라갈 수 있습니다.

## 4. 권한에 따라 보이는 메뉴

| 구분 | 사용할 수 있는 화면과 기능 |
|---|---|
| 직원 | **홈 · 장례업무 · 파트 게시판**. 본인의 행사·보고서·정산·봉투·휴무/당직을 관리하고, 소속 파트 게시판에서 글과 댓글을 작성합니다. |
| 파트장 | 직원용 기능에 **서식 · 회사 서류 · 설정**이 추가됩니다. 주간보고·회의록·후기보고·탁송·출고 서식을 사용하고, 본인이 만든 파트와 파트원을 관리합니다. |
| 총괄실장 | **취합 · 서식 · 회사 서류 · 설정**을 사용합니다. 파트장들이 서버에 올린 주간보고·회의록·후기·탁송 기록을 열람·취합하고, 주간보고·회의록 취합에 특이사항과 보고사항을 추가합니다. 홈·장례업무·파트 게시판은 사용하지 않습니다. |

파트장은 **자기가 만든 파트의 파트원**이 서버에 저장한 장례일정·정산 상태·봉투 기록을 조회할 수 있습니다. 이 화면은 **보기만 가능**하며 파트원 기록을 대신 수정하지 않습니다. 다른 파트의 게시판이나 파트원 명단은 볼 수 없습니다. 일반 직원에게 서식·회사 서류·통합 앱의 설정 메뉴는 보이지 않지만, **장례업무 안의 「내 계정 · 백업」은 사용할 수 있습니다.**

직원의 권한을 바꾸는 **「설정 → 직원 권한」은 별도로 관리자 권한을 받은 계정에만** 보입니다. 모든 파트장이 다른 사람의 권한을 바꿀 수 있는 것은 아닙니다. 권한이 변경되면 인터넷에 연결한 상태에서 앱을 다시 열어 확인하세요.

## 5. 서버 자동 저장 확인하기

로그인 후 각 화면에서 저장한 기록을 내 계정의 서버 기록과 자동으로 맞춥니다. 장례업무뿐 아니라 **서식과 회사 서류도 서버 저장 대상**입니다.

| 업무 | 서버에 저장하는 주요 기록 | 저장 상태를 확인하는 곳 |
|---|---|---|
| 장례업무 | 행사·보고서 입력·정산·봉투, 업무 설정, 휴무/당직 | 장례업무 위쪽의 「실시간 저장됨」 표시, **설정 → 내 계정 · 백업 → 실시간 저장 · 내 계정**의 마지막 저장 시각 |
| 서식 | 주간보고·회의록·후기·탁송·출고, 이미지·설정·서명, 총괄실장 취합 작성 내용 | 통합 앱 **설정 → 데이터**의 「서버 자동 저장 켜짐 · 마지막 저장 …」 |
| 회사 서류 | 문서·직원 기록·이미지·직인·회사 정보 | **서식 → 회사 서류 → 설정 → 데이터**의 「서버 자동 저장 켜짐 · 마지막 저장 …」 |

- 인터넷이 끊기거나 서버 저장에 실패하면 기기에 먼저 보관하고, 연결이 돌아오면 다시 저장을 시도합니다. 「올리는 중」이나 「연결 끊김 · 이 기기에 보관」 상태는 서버 저장 완료가 아닙니다.
- 장례업무에서는 **「지금 맞추기」**로 서버 기록과 다시 맞출 수 있습니다. 서식·회사 서류는 해당 화면을 열어 두고 마지막 저장 시각이 갱신되는지 확인하세요.
- 입력 화면에 저장 버튼이 있다면 먼저 저장을 마치세요. 서버 자동 저장은 아직 저장하지 않은 입력까지 보장하지 않습니다.
- **홈만 열었다고 모든 업무 기록의 이동이 끝나는 것은 아닙니다.** 장례업무와, 권한이 있는 서식·회사 서류 화면을 각각 열어 기록과 저장 상태를 확인하세요.
- 서버 기록은 계정별로 관리됩니다. 다만 위 권한 안내처럼 파트장은 소속 파트원의 업무 기록을, 총괄실장은 파트장이 올린 서식 기록을 정해진 화면에서 조회할 수 있습니다.

**서버 자동 저장과 파일 백업은 함께 사용하세요.** 서버에 한 번도 올라가지 않은 예전 기록이나 연결이 끊긴 동안의 기록은 새 기기에서 로그인하는 것만으로 복원되지 않습니다. 삭제한 기록도 서버에 반영될 수 있으므로 서버 저장을 과거 기록의 별도 백업으로 생각하면 안 됩니다.

## 6. 휴대폰·PC를 바꿀 때 기록 복원하기

1. 이전 기기에서 필요한 기록을 **파일로 백업**하고, 각 업무 화면의 **서버 저장 완료와 마지막 저장 시각**을 확인합니다.
2. 새 기기에서 통합 앱을 열고 **기존과 같은 계정으로 로그인**합니다. 설치해서 쓸 경우 설치한 앱에서 진행하세요.
3. 직원·파트장은 **장례업무를 한 번 열어** 서버 기록을 기기에 받아옵니다. 파트장·총괄실장은 서식과 회사 서류도 각각 열어 기다립니다.
4. 이전 기기와 새 기기의 행사·봉투·서식·회사 서류를 비교합니다. 누락된 기록은 아래 표의 해당 메뉴에서 백업 파일을 불러옵니다.
5. 불러온 기록과 서버 저장 상태를 다시 확인합니다. 확인 전에는 이전 기기의 앱·브라우저 데이터를 지우거나 기기를 초기화하지 마세요.

**복원되는 것은 해당 계정으로 서버에 저장된 기록입니다.** 기록이 보이지 않으면 로그인 계정, 조회 중인 달, 인터넷 연결과 저장 상태부터 확인하세요. 기기를 바꾸려고 「회원 탈퇴」를 누르면 안 됩니다. 회원 탈퇴는 계정과 서버 기록을 삭제하는 기능입니다.

## 7. 백업 파일 받기와 불러오기

백업은 화면 사진이나 보고서 PDF가 아닌 **`.json` 파일**로 받습니다. 예전 앱에서 받은 파일도 아래의 대응하는 메뉴에서 불러올 수 있습니다.

| 기록 종류 | 파일 받기 | 통합 앱에서 불러오기 |
|---|---|---|
| 관리자 서식 | 기존 관리자 서식 또는 통합 앱 **설정 → 데이터 → 백업 파일 저장**. 파일명은 `관리자서식_백업_날짜.json`입니다. | 통합 앱 **설정 → 데이터 → 백업 불러오기** |
| 장례일정·정산·봉투·휴무/당직 | 예전 장례일정 아이콘의 안내 화면에서 **기록 백업 파일 받기**, 또는 장례업무 **설정 → 내 계정 · 백업 → 행사 기록 보관 → 전체 기록 백업 파일 저장**. 파일명은 `장례일정_전체백업_날짜.json`입니다. | **장례업무 → 설정 → 내 계정 · 백업 → 행사 기록 보관 → 백업 불러오기** |
| DW관리·회사 서류 | 예전 DW관리 아이콘의 안내 화면에서 **기록 백업 파일 받기**, 또는 회사 서류 **설정 → 데이터 → 백업 파일 저장**. 파일명은 `회사서류_백업_날짜.json`입니다. | **서식 → 회사 서류 → 설정 → 데이터 → 백업 불러오기** |

- **관리자 서식 백업에는 같은 저장 공간에서 읽을 수 있는 장례업무·휴무 기록도 포함되지만, 회사 서류는 포함되지 않습니다.** 회사 서류는 따로 백업하세요. 아이폰의 다른 홈 화면 앱에만 남은 기록은 그 앱에서도 따로 받아야 합니다.
- 관리자 서식 백업을 통합 앱 설정에서 불러올 때 이미 장례업무 기록이 있으면 그 장례업무 기록은 그대로 둡니다. 빠진 행사·봉투를 합치려면 **장례업무의 「백업 불러오기」에서 같은 관리자 서식 백업 파일을 선택**할 수 있습니다.
- 불러오기는 기록 종류에 따라 빠진 기록을 추가하거나 더 최근에 고친 기록을 반영합니다. 모든 내용을 무조건 덮어쓰는 기능은 아니므로, 불러온 뒤 해당 기록을 확인하세요. 회사 서류 메뉴가 없는 직원은 관리자에게 권한을 확인받으세요.
- **「설정 내보내기 (복사)」는 행사 기록 전체 백업이 아닙니다.** 행사 기록은 반드시 「전체 기록 백업 파일 저장」으로 받으세요.
- 장례업무의 **「자동 보관본」은 같은 기기 안에 있는 사본**입니다. 앱·브라우저 데이터가 지워지는 상황에 대비하려면 외부에 저장한 백업 파일이 필요합니다.
- **「휴대폰 파일 자동 백업」은 지원하는 브라우저에서 별도로 켜는 기능**입니다. 지원하지 않는 기기에서는 위의 수동 백업을 사용하세요. 이 자동 백업에도 회사 서류는 포함되지 않습니다. 설정의 「클라우드 자동 저장」도 별도로 연결하는 구글 드라이브 기능이며, 로그인 계정의 Supabase 서버 자동 저장과는 다릅니다.
- 파일은 다운로드·파일 앱 등에서 실제로 저장됐는지 확인하고, 기기를 바꿀 때도 꺼낼 수 있는 본인 보관 장소에 사본을 두세요. 고인·상주·직원 개인정보가 들어 있으므로 단체방이나 공개 저장소에 올리지 마세요.
